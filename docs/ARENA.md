# Numchess Arena (local preview)

Phase 8 competitive features are **local-only** in this repo (no Supabase/ELO yet).

## Enabled in app

- **Arena move clock** — optional per-move countdown (`Match settings` on `/play`).
- **Opening swap** — alternates first player each new game when enabled.
- **Random first player** — optional fair start.

## Not in MVP (requires ADR + backend)

- Fischer/simple clock enforcement
- ELO and authenticated accounts
- Public replay gallery
- Ranked tiebreak beyond Classic draw

Online ranked play is Phase 7 (PartyKit) — intentionally not shipped here.
